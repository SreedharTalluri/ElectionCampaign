# Campaign images

Place the fixed site images in this folder using these filenames:

- `candidate-photo.jpg` — first candidate photo shown on the campaign home page
- `candidate-photo-2.jpg` — second candidate photo; the page rotates between both photos every second
- `party-logo.png` — party logo shown in the header on both pages

The site keeps its text/letter placeholders visible until the first image files are added. The carousel starts rotating once both candidate photos are available.
